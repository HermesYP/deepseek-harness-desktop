# Adversarial review — overclaiming audit of the deliverable set (Phase 5)

Audit of `docs/README.md`, `docs/decisions/0001-desktop-architecture.md`, `docs/decisions/0002-non-rust-runtime-requirements.md`, `docs/parity-matrix.md`, `docs/verification-report.md`, `docs/limitations.md`, `docs/reference-environment.md`, `docs/build-and-install.md`, and the three contracts plus `docs/contracts/tauri-contract.md`, against the read-only reference `_upstream/` (commit `477b4f420553e8a52c2fbccc464d7561b239c443`) and the delivered `port/` tree.
Severity: `blocker` = a claim a reader would rely on that is false or unbacked; `major` = material overclaim or contradiction; `minor` = local defect; `nit` = wording.
Audit stance: adversarial; every finding quotes the audited text and names the contradicting evidence. Nothing below is inferred from the project name.
